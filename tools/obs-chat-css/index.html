OBSライブチャットCSSジェネレーター

YouTube Live や Twitch のコメント欄を、OBSの「カスタムCSS」に貼るだけで読みやすく整えるジェネレーターです。文字サイズ・透過率・影・自動フェードアウトをプレビューで調整して、そのまま1クリックコピーできます。

登録不要 / CSSをコピペするだけ

デザイン設定

出力先プラットフォーム
ベーステーマ（4種）
表示オプション
OBS Live Chat Preview · Editorial Paper

OBS「カスタムCSS」貼り付け用コード


            

          

        


        
        
    
          
  1. 
            
    STEP 01
    
            
    チャットのポップアウトURLを取得
    
            
    YouTube Studioの配信管理画面でチャット右上のメニューから「チャットをポップアウト」を開き、URLをコピーします。
    
          
    2. 
          
  2. 
            
    STEP 02
    
            
    OBSでブラウザソースを追加
    
            
    ソースの「＋」→「ブラウザ」を選び、URL欄に貼ります。幅は420〜520、高さは600〜800あたりが扱いやすいです。
    
          
    3. 
          
  3. 
            
    STEP 03
    
            
    カスタムCSS欄に全置き換え
    
            
    「カスタムCSS」にもともと入っている数行を消して、このツールでコピーしたCSSをそのまま貼り付けます。
    
          
    4. 
          
  4. 
            
    STEP 04
    
            
    OKを押してキャッシュ再読込
    
            
    反映が遅いときはプロパティ下部の「現在のページのキャッシュを再読み込み」を1回押すと切り替わります。
    
          
    5. 
        


        
        

          

            
チャットと並べて使える、手元操作のタイマー＆目標バー

            
TokiDock（作業タイマー・時計）と GoalDock（登録者目標バー・お題ルーレット）は、OBSカスタムブラウザドックから配信画面にボタンを映さず操作できます。無料Lite版あり。
